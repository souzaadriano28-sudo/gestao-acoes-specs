# Protótipo de login — Atlas Carteira

Protótipo estático de alta fidelidade para aprovação visual. Ele não implementa autenticação e não utiliza credenciais reais.

- `index.html`: composição responsiva e interação demonstrativa de mostrar/ocultar senha.
- `login-desktop-1440x1024.png`: referência desktop.
- `login-mobile-390x844.png`: referência mobile.
- `render.mjs`: renderização determinística com o Playwright já disponível no frontend.

Os textos deixam explícitos a finalidade acadêmica, o uso planejado de sessão por cookie HttpOnly e a ausência de cadastro, recuperação e login social nesta fase.
